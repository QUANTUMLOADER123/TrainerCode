========================================================================
                      TrainerCode 2000 (Win32 Edition)
         Среда системного обучения языкам C и C++ (x86 / x64)
========================================================================

Благодарим за использование TrainerCode 2000!

ОСОБЕННОСТИ ПРОГРАММЫ:
- Аутентичный интерфейс в стиле Windows 2000 (строгие формы без скруглений).
- 25 содержательных уроков: от базовых типов данных и циклов до указателей,
  стека, кучи, структур, ООП, vtable, RAII, шаблонов и многопоточности.
- Встроенный ИИ-наставник TrainerAI:
  * Анализ исходного кода на утечки памяти (malloc без free, new без delete).
  * Нахождение разыменования NULL-указателей и опасных переполнений.
  * Пошаговые подсказки к заданиям и объяснения теории.
  * Поддержка загрузки моделей GGUF (Llama / SmolLM / Qwen) или подключение к Ollama.
- Интеграция с компиляторами:
  * Microsoft Visual Studio (cl.exe).
  * MinGW GCC / Clang.
  * Встроенный валидатор решений.
- Справочник фундаментальных типов данных C/C++ (x86 vs x64).

ЗАПУСК:
Просто запустите TrainerCode.exe на любой версии Windows (7, 8, 10, 11).
Никаких дополнительных библиотек не требуется (чистый Win32 PE64).
