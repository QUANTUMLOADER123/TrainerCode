# 💻 TrainerCode 2000 — Элитная среда обучения языкам C и C++

> **«Тот, кто знает C и C++, управляет каждым байтом и каждым тактом процессора.»**  
> Профессиональное настольное приложение в аутентичном ретро-стиле **Windows 2000** с интегрированным редактором кода, ИИ-наставником **TrainerAI** (с поддержкой загрузки GGUF / LLaMA), 25 фундаментальными практическими модулями и гибким выбором компилятора (Microsoft Visual Studio, GCC MinGW, Clang).

---

## 📸 Внешний вид и стиль 2000-х
- **Строгий ретро-интерфейс**: никаких скруглений, классическая палитра `Windows 2000` (`#d4d0c8`, `#000080`), рельефные 3D-бордеры (outset/inset).
- **Мастер начальной настройки (Onboarding Wizard)**: персональное приветствие, выбор уровня подготовки (с нуля / базовый / сеньор), мотивирующая похвала.
- **Трехпанельная рабочая среда**:
  1. *Слева*: Иерархическое дерево 25 уроков по модулям со статусами прохождения.
  2. *Сверху-справа*: Вкладки «Редактор Кода & Решение» с моноширинным шрифтом и «Учебник и Теория Урока».
  3. *Снизу-справа*: «Консоль вывода / Лог компилятора» и «ИИ-Ассистент TrainerAI».
- **Строка состояния**: отслеживание номера урока, текущего языка (C11 / C++20), статуса компилятора и профиля ученика.

## 🚀 Возможности программы

### 1. 📚 25 Обширных Уроков от Нуля до Архитектора
Обучение структурировано по 6 ключевым модулям:
- **Модуль 1: Фундамент языка C и архитектура ЭВМ**
  - Урок 1: Архитектура, регистры, структура файла, `main`, `printf`.
  - Урок 2: Фундаментальные типы данных, память, `sizeof`, `limits.h`, спецификаторы формата.
  - Урок 3: Ввод данных, `scanf`, ветвления `if / else`, логические операторы.
  - Урок 4: Циклы `for`, `while`, `do-while`, операторы `break` и `continue`.
  - Урок 5: Побитовые операции (`&`, `|`, `^`, `~`, `<<`, `>>`) и битовые маски.
- **Модуль 2: Функции, Стек и Память**
  - Урок 6: Функции, Call Stack, передача по значению, спецификаторы `static` и `inline`.
  - Урок 7: Рекурсия, базовый случай и предотвращение Stack Overflow (0xC00000FD).
- **Модуль 3: Массивы, Строки и Указатели**
  - Урок 8: Непрерывная память массивов, границы и Buffer Overflow.
  - Урок 9: Строки как нуль-терминированные массивы `char[]` (`\0`), функции `<string.h>`.
  - Урок 10: **УКАЗАТЕЛИ (Pointers)**: операторы `&` и `*`, адресация в RAM, разыменование, арифметика указателей.
  - Урок 11: Указатели на функции и Callbacks (основа для событий и `qsort`).
- **Модуль 4: Динамическая Память и Пользовательские Типы**
  - Урок 12: Память в куче (Heap): `malloc`, `calloc`, `realloc`, `free`, утечки памяти.
  - Урок 13: Структуры (`struct`), объединения (`union`), `typedef` и Structure Padding (выравнивание).
  - Урок 14: Файловый ввод-вывод: текстовые и бинарные потоки `FILE*`, `fopen`, `fclose`.
- **Модуль 5: Переход к C++ и Объектно-Ориентированное Программирование**
  - Урок 15: Переход к C++: потоки `std::cout`/`std::cin`, ссылки `&` vs указатели, перегрузка функций.
  - Урок 16: Классы и Инкапсуляция: `private`/`public`, конструкторы, списки инициализации, деструкторы.
  - Урок 17: Наследование, Полиморфизм, ключевое слово `virtual`, таблица виртуальных функций (`vtable`), абстрактные классы.
- **Модуль 6: Modern C++ и Стандартная Библиотека STL**
  - Урок 18: Управление ресурсами: идиома RAII, rvalue-ссылки `&&`, `std::move`.
  - Урок 19: Умные указатели (Smart Pointers): `std::unique_ptr`, `std::shared_ptr`, `std::weak_ptr`.
  - Урок 20: Шаблоны (Templates) функций и классов, `constexpr`.
  - Урок 21: Контейнеры STL: `std::vector`, `std::map`, `std::unordered_map` и их асимптотика O(1) / O(log N).
  - Урок 22: Лямбда-выражения и алгоритмы STL (`std::count_if`, `std::sort`).
  - Урок 23: Обработка исключений (`try-catch-throw`), раскрутка стека и `noexcept`.
  - Урок 24: Многопоточность: `std::thread`, `std::mutex`, `std::lock_guard`, атомики `std::atomic`.
  - Урок 25: Финальный курсовой проект: реализация собственного динамического контейнера `Vector` с нуля.

### 2. 🤖 ИИ-Ассистент TrainerAI
- **Аудит кода на безопасность**: мгновенно находит утечки памяти (`malloc` без `free`, `new` без `delete`), забытые точки с запятой, проблемы разыменования `NULL`.
- **Объяснение концепций**: простыми словами с точки зрения регистров процессора и памяти объясняет, как работает указатель, таблица `vtable` или семантика перемещения.
- **Менеджер моделей**:
  - Поддержка загрузки легковесных GGUF моделей (SmolLM2-360M, TinyLlama-1.1B, Qwen2.5-Coder-1.5B).
  - Возможность интеграции с локальным сервером Ollama (`localhost:11434`) или LM Studio.
  - Полноценная работа в оффлайн-режиме со встроенным движком базы знаний.

### 3. ⚙ Настройки Компилятора
- Выбор компилятора: **Microsoft Visual Studio (cl.exe)**, **MinGW-w64 GCC**, **Clang**, встроенный симулятор.
- Выбор директории установки и исполняемого файла с диалогом обзора.

- Кнопка встроенного тестирования компилятора.

Сводная таблица по клавише F1:

## 📦 Сборка и Готовый .EXE

В папке `build/` находится уже скомпилированный нативный Windows 64-bit исполняемый файл:
- **`build/TrainerCode.exe`** (PE32+ executable for MS Windows x86-64 GUI).
- **`build/TrainerCode-v1.0.0-windows-x64.zip`** (полный архив с конфигурацией).

### Сборка из исходников (на Linux или Windows через Zig / MinGW):
```bash
make build
```
Команда собирает `build/TrainerCode.exe` с полным Win32 GUI, связывая системные библиотеки `comctl32`, `gdi32`, `winhttp`, `shell32`, `comdlg32`.
