📖 Системный справочник функций Windows API (Win32)

OpenProcess: Получение дескриптора процесса по его PID.
HANDLE OpenProcess(DWORD dwDesiredAccess, BOOL bInheritHandle, DWORD dwProcessId);

ReadProcessMemory: Чтение байт из виртуальной памяти другого процесса.
BOOL ReadProcessMemory(HANDLE hProcess, LPCVOID lpBaseAddress, LPVOID lpBuffer, SIZE_T nSize, SIZE_T *lpNumberOfBytesRead);

WriteProcessMemory: Запись байт в память другого процесса.
BOOL WriteProcessMemory(HANDLE hProcess, LPVOID lpBaseAddress, LPCVOID lpBuffer, SIZE_T nSize, SIZE_T *lpNumberOfBytesWritten);

VirtualProtectEx: Смена прав доступа страницы памяти (PAGE_EXECUTE_READWRITE для NOP-патчинга).
BOOL VirtualProtectEx(HANDLE hProcess, LPVOID lpAddress, SIZE_T dwSize, DWORD flNewProtect, PDWORD lpflOldProtect);

CreateToolhelp32Snapshot: Создание снимка запущенных процессов и модулей.
HANDLE CreateToolhelp32Snapshot(DWORD dwFlags, DWORD th32ProcessID);
